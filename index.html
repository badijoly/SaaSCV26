Diseño basado en microservicios desacoplados sobre AWS, combinando modelos de lenguaje de visión y almacenamiento relacional estructurado:

Frontend & UX

React, Next.js, Tailwind CSS, TypeScript. Interfaz moderna, accesible para personal no técnico en faena.

Backend & APIs

Python FastAPI para microservicios numéricos y de IA; arquitectura REST/GraphQL asíncrona.

Infraestructura Cloud

AWS (ECS/Fargate o Lambdas, Aurora PostgreSQL, S3 con encriptación SSE-S3/KMS, CloudFront).

Inteligencia Artificial

Modelos multimodales de visión (Claude 3.5 Sonnet / GPT-4o) calibrados para DTEs chilenos y glosas mineras.

Normativas & Factores

Factores oficiales HuellaChile (MMA), SEN (Coordinador Eléctrico), GHG Protocol Corporate Standard e ISO 14064.

Auditoría Criptográfica

Hash SHA-256 para trazabilidad inmutable entre factura, factor de emisión y registro de CO2e.
